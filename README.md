# astrbot_plugin_cute_face

让 bot 在短消息后面自动追加匹配情感的 QQ 小表情。

通过 LLM 判断消息情绪，从角色专属表情池中选出最合适的表情追加到消息末尾。每个 bot 实例可以配置不同的表情池，体现不同的角色性格。

## 效果

bot 回复「好的知道了」→ LLM 判断这是轻松肯定的语气 → 从表情池里选出 124(OK) 和 232(佛系) → 消息变成「好的知道了 [OK][佛系]」

## 安装

将 `astrbot_plugin_cute_face` 文件夹放入 AstrBot 的 `data/plugins/` 目录，重启 AstrBot。

要求 AstrBot >= 4.5.7（需要 `llm_generate` 和 `get_current_chat_provider_id` API）。

## 配置项

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| emoji_pool | list | [179] | 表情 ID 池，LLM 从中选取匹配情感的表情 |
| max_text_length | int | 35 | 触发阈值，纯文本字数不超过此值才追加表情 |
| probability | float | 0.6 | 追加概率，0.0~1.0 |
| min_faces | int | 1 | 每次最少追加几个表情 |
| max_faces | int | 3 | 每次最多追加几个表情 |

## 工作原理

1. 通过 `on_decorating_result` 钩子在消息发送前拦截
2. 检查消息链是否为纯文本短消息（不含图片/语音/视频，字数在阈值内）
3. 按概率决定是否触发
4. 调用当前会话的 LLM，将表情池（含中文名称）和消息内容一起发过去，让 LLM 选出最匹配的表情
5. 将 Face 组件追加到消息链末尾
6. 如果 LLM 调用失败，自动回退到随机选取

## 关于分段

如果表情和文字被分成两条消息发送，需要修改 AstrBot 的分段正则表达式。

将分段正则从默认值改为：

```
[\s\S]+
```

这会让整条消息作为一段发送，表情和文字在同一个气泡里。
