# astrbot_plugin_cute_face

双向 QQ 小表情增强插件。

**发表情**：bot 回复短消息时，通过 LLM 判断情感从角色专属表情池中选出匹配的表情追加到消息末尾。

**读表情**：用户发送的 QQ 小表情会被翻译成 `(表情:名称)` 的文字描述，让 LLM 能理解表情含义并做出相应回应。

## 效果

发表情：bot 回复「好的知道了」→ LLM 从表情池选出 OK 和佛系 → 「好的知道了 [OK][佛系]」

读表情：用户发「你说得对 [doge]」→ LLM 看到「你说得对 (表情:doge)」→ bot 理解这是在阴阳怪气

## 安装

将 `astrbot_plugin_cute_face` 文件夹放入 AstrBot 的 `data/plugins/` 目录，重启 AstrBot。

要求 AstrBot >= 4.5.7。

## 配置项

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| emoji_pool | list | [179] | 表情 ID 池，LLM 从中选取匹配情感的表情 |
| max_text_length | int | 35 | 触发阈值，纯文本字数不超过此值才追加表情 |
| probability | float | 0.6 | 追加概率，0.0~1.0 |
| min_faces | int | 1 | 每次最少追加几个表情 |
| max_faces | int | 3 | 每次最多追加几个表情 |
| reply_with_quote | bool | true | 追加表情时是否引用回复原消息 |
| face_reading | bool | true | 是否翻译用户发的表情为文字 |

## 工作原理

### 发表情
1. `on_decorating_result` 钩子在消息发送前拦截
2. 检查是否为纯文本短消息
3. 调用 LLM 从表情池中选出匹配情感的表情
4. 追加 Face 组件，同时设置 `result_content_type = None` 防止分段
5. 手动补上 Reply 组件保持引用回复

### 读表情
1. `on_message` 钩子在消息到达 LLM 之前拦截
2. 遍历消息链，将 Face 组件替换为 `(表情:名称)` 的 Plain 文本
3. 更新 `message_str`，使 LLM 能读到表情含义

## 关于分段

插件已内置防分段处理：追加表情后会自动将消息的 `result_content_type` 设为 `None`，使其跳过 AstrBot 的 LLM 分段流水线。

## 表情池配置示例

温柔角色：`[14, 21, 6, 63, 175, 212, 214, 116, 307, 111, 106, 176]`

活泼角色：`[13, 4, 76, 43, 99, 74, 180, 182, 290, 319, 315, 320, 271, 277]`

冷淡角色：`[284, 287, 270, 269, 232, 281, 268, 314, 14, 174, 96, 75]`

内置 203 个 QQ 表情 ID 到中文名的映射，覆盖绝大多数常用表情。
